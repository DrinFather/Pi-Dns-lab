# Sample data

Small, anonymized samples of DNS log lines for testing `scripts/dns_analyzer.py`.

Before you add a file:
- Replace your device IPs with `192.168.X.X`
- Delete any lookups that reveal personal stuff (banking, school portals, accounts)
- Keep it short, a few hundred lines at most
- Save it as `.txt`. Files ending in `.log` are blocked by `.gitignore` so a raw log can't get committed by accident.
